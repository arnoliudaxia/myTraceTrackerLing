
## 🔧 技术说明

### 坐标纠正

国内地图 APP（如高德、腾讯地图）使用 GCJ-02（火星坐标系），而国际标准使用 WGS84 坐标系。本工具自动进行坐标纠正：

纠正公式：

```javascript
// 计算偏移量
dLat = transformLat(lng - 105.0, lat - 35.0);
dLng = transformLng(lng - 105.0, lat - 35.0);

// 应用反向纠正
correctedLat = lat - dLat;
correctedLng = lng - dLng;
```

### 数据过滤

为提高可视化质量，先使用独立脚本过滤数据：

- **规则**：如果某天的轨迹点不超过指定阈值，则认为该天没有有效数据；默认阈值为 10，可通过 `--threshold` 修改
- **目的**：避免稀疏数据点造成轨迹断裂或误导
- **清洗脚本**：`scripts/filter-csv-days.mjs` 可直接覆盖原始 CSV，并保留原始数据行格式
- **生成脚本**：`scripts/generate-data.mjs` 不再依赖 `date` 字段；缺少该字段时会从 `dayTime` 或 `geoTime` 计算

### 速度路径可视化

页面支持“速度路径”按钮，会读取 CSV 中的 `speed` 字段并按相邻轨迹点的平均速度为路径分段着色。路径会根据速度值细分并插值着色，颜色从蓝色到红色表示当前显示范围内从低到高的速度变化，右下角图例会显示当前路径选择的最低和最高速度。

### 路径分段

页面会根据相邻轨迹点的 `geoTime` 时间差自动切分路径。默认阈值为 1 小时：如果两个相邻点之间间隔超过 1 小时，则认为路径发生断开并开始新的路径段。

生成轨迹数据时还会检查相邻两天：如果前一天最后一段路径和后一天第一段路径的时间差不超过 1 小时，则把后一天第一段合并到前一天的最后一段；后一天会从原来的第二段路径开始显示。

选择“全部”时会显示当天所有路径段；点击路径编号按钮可多选路径段，被选中的路径正常显示，未选中的路径段默认以 30% 透明度显示，并可通过“弱化透明度”滑块调整。轨迹点数、时间段、海拔范围、速度范围等信息卡片会跟随所选路径段重新统计。速度路径也会跟随同样的路径段选择。

### 路径标签

路径标签保存在 `data.db` SQLite 数据库的 `path_labels` 表中，不写入轨迹数据表。使用 key-value 结构，key 由日期和路径 index 组成，例如 `2024-05-03#0` 表示 2024-05-03 的第 1 段路径。页面会根据标签自动生成顶部按钮网格；选择一个或多个标签后，会跨不同日期同时显示这些标签对应的路径，此时日期选择暂时无效并置灰。在日期模式下，“快捷打标签”区域会列出已有标签，点击即可把该标签应用到当前选中的路径段，也可以点击“清除标签”移除当前选中路径段的标签。每次标签内容发生变化后，页面会通过本地 Node 服务自动静默保存到数据库。

### 路径收藏

路径收藏保存在 `data.db` SQLite 数据库的 `path_favorites` 表中，不写入轨迹数据表。同样使用 key-value 结构，key 由日期和路径 index 组成，value 保存备注 `note` 和收藏时间 `createdAt`。页面会在收藏夹中显示已收藏路径、对应备注和路径时间范围；点击收藏项会切回日期模式，跳转到对应日期并选中该路径段。每次收藏或取消收藏后，页面会通过本地 Node 服务自动静默保存到数据库。

### 依赖库

- **Node.js**：
  - 使用 Node.js 22+ 内置模块处理 CSV、JSON、SQLite 和本地 HTTP 服务
  - 无需安装第三方 npm 依赖
  - 数据存储使用 `node:sqlite`（Node 22 内置）

- **前端**：
  - [Leaflet.js](https://leafletjs.com/) v1.9.4 - 地图可视化库
  - OpenStreetMap / Esri World Imagery / 天地图 WMTS - 地图瓦片服务

## 📊 数据格式

### CSV 数据格式

| 字段名    | 类型  | 说明           | 示例          |
| --------- | ----- | -------------- | ------------- |
| latitude  | float | 纬度           | 31.2304       |
| longitude | float | 经度           | 121.4737      |
| geoTime   | int   | 时间戳（毫秒） | 1727834853441 |
| altitude  | float | 海拔高度（米） | 25.23         |
| speed     | float | 速度（米/秒）  | 1.25          |

### 数据库存储

所有数据保存在 `data.db` SQLite 数据库中，包含以下表：

- `tracks` - 每日轨迹汇总（日期、点数、起止时间、海拔/速度范围）
- `track_points` - 每日轨迹点（坐标、时间戳、海拔、速度、时间）
- `path_labels` - 路径标签（日期、路径段索引、标签文本）
- `path_favorites` - 路径收藏（日期、路径段索引、备注、收藏时间）

### 路径标签格式

```json
{
  "2024-05-03#0": "通勤",
  "2024-05-03#2": "散步"
}
```

### 路径收藏格式

```json
{
  "2024-05-03#0": {
    "note": "这一段风景很好",
    "createdAt": "2026-05-05T12:00:00.000Z"
  }
}
```

`generate-data.mjs` 会读取字段：

- `latitude`
- `longitude`
- `geoTime`
- `dayTime`
- `altitude`
- `speed`

日期优先级：

1. 如果 CSV 有 `date` 字段，直接使用
2. 否则用 `dayTime`
3. 再否则用 `geoTime`

所有日期按 `Asia/Shanghai` 处理。

**数据库结构**
`lib/db.mjs` 初始化 4 张表：

- `tracks`：每日轨迹汇总，包含日期、点数、起止时间、海拔/速度范围
- `track_points`：每日轨迹点，包含坐标、时间戳、海拔、速度、显示时间
- `path_labels`：路径段标签
- `path_favorites`：路径段收藏


标签和收藏的 key 逻辑是：

```text
日期#路径段索引
```

例如：

```json
{
  "2024-05-03#0": "通勤"
}
```

收藏格式是：

```json
{
  "2024-05-03#0": {
    "note": "这一段风景很好",
    "createdAt": "2026-05-05T12:00:00.000Z"
  }
}
```
